## 🌟 Key Capabilities
1. **Deterministic Quantitative Risk Suite:** Annualized Volatility (σ), Beta (β vs NIFTY 50), and HHI Concentration Index.
2. **SEBI Safety Guardrail:** Algorithmic verification prevents speculative claims and attaches statutory disclaimers.
3. **9-Tab Comprehensive Cockpit:** Overview, Holdings Telemetry, Quantitative Risk, Markets, News, Watchlist, SIP Calculators, Grounded AI Analyst, and SQLite Audit Logs.
4. **Dynamic Data Ingestion:** Real-time CSV and JSON portfolio file ingestion with live metric and chart re-rendering.

## 🛠️ Tech Stack
FastAPI, Python, SQLite, Chart.js, Tailwind CSS
